# Schr1 — сайт «Schreinerei Tannrieder»

Портфолио-проект Максона: сайт вымышленной семейной столярной мастерской из Верхней Баварии. Полный бриф — `docs/BRIEF.md`, оглавление в начале файла. Перед задачей читай только тот раздел брифа, который к ней относится, а не весь файл.

## Как работать
- Одна задача — одна беседа. Делай только то, что просят, чужой код не трогай.
- Задача неясна или спорит с брифом — спроси. Не угадывай.
- Перед правками перечисли файлы, которые изменишь.
- После правок запусти `npm run typecheck`, `npm run lint` и тесты этого места. Ошибки исправь до сдачи.
- Отвечай по-русски. Код, имена файлов и переменных — по-английски. Тексты сайта — по-немецки и по-английски, только через файлы переводов.

## Стек (менять только с согласия Фёдора)
- Node.js 26 LTS, npm
- Next.js 16 (App Router), React 19, TypeScript в строгом режиме
- Payload CMS 3 в том же приложении, PostgreSQL на Neon, файлы в Vercel Blob
- Tailwind CSS 4, шрифты через `next/font`
- next-intl: немецкий по умолчанию (без префикса в адресе), английский под `/en`
- 3D: `three`, `@react-three/fiber`, `@react-three/drei`; GSAP + ScrollTrigger + `@gsap/react`; Lenis
- Формы: Server Actions + Zod. Письма: Resend
- Тесты: Vitest, Playwright, `@axe-core/playwright`. Линтер и форматтер: Biome

## Жёсткие правила
1. `cacheComponents` в `next.config.ts` НЕ включать: Payload 3 его полностью не поддерживает.
2. Папку `src/app/(payload)` руками не править — её генерирует Payload.
3. Весь текст интерфейса — только в `messages/de.json` и `messages/en.json`. Весь контент (услуги, работы, вакансии, команда, настройки) — только из Payload.
4. Цвета, шрифты, отступы — только из токенов в `src/app/(frontend)/globals.css` (блок `@theme`). Своих случайных значений не вводить.
5. Картинки — только через `next/image` и только с alt-текстом.
6. Браузер посетителя не ходит на чужие домены: никаких шрифтов с CDN, аналитики, Google Maps, YouTube, виджетов, пресетов drei (`<Environment preset>`), декодеров с gstatic. Всё отдаём со своего домена.
7. На публичных страницах нет ни одной cookie. В next-intl отключена cookie языка (`localeCookie: false`).
8. Серверные компоненты по умолчанию. `"use client"` — только там, где нужна интерактивность.
9. Без `any`, без `@ts-ignore`, без закомментированного кода.
10. Новая зависимость — только с согласия. Перед установкой проверь, что пакет живой и совместим с нашими версиями.
11. Секреты — только в `.env.local`. В репозиторий идёт только `.env.example` без значений.
12. Никакого «Lorem ipsum», выдуманных счётчиков («500+ клиентов») и эмодзи вместо иконок.
13. Анимации появления блоков при прокрутке запрещены. Единственная большая анимация — 3D-сцена (раздел 4 в `docs/BRIEF.md`). Всё уважает `prefers-reduced-motion`.

## Демо-режим (фирма вымышленная)
- В продакшене `SITE_INDEXING=false`: на всех страницах `noindex`, robots.txt запрещает обход.
- В подвале и у форм есть пометка: «Konzeptprojekt – die Schreinerei Tannrieder ist ein fiktives Unternehmen.»
- Письма из форм уходят только на почту Максона. Заявки нигде не хранятся.
- Телефон — только «драма-номер» 089 99998 412, почта — только на домене `.example`.
