# Макет сайта Schreinerei Tannrieder

Эталон внешнего вида сайта. Фронтенд делаем так, чтобы он выглядел как здесь: те же цвета, шрифты, размеры, отступы и порядок блоков. Макет сделан по брифу (раздел 3 «Дизайн») и дан Фёдором.

Открыть: двойной клик по любому `.html` — откроется в браузере. Интернет не нужен, шрифты лежат в `assets/`.

## Файлы

| Файл | Что это |
|---|---|
| `01-startseite-desktop.html` | Главная на компьютере, все блоки сверху вниз |
| `02-3d-szene-schritte.html` | Раскадровка 3D-сцены «Vom Brett zum Schrank»: шесть шагов и подписи к ним |
| `03-anfrage-desktop.html` | Форма заявки, шаг 1. Специально показано состояние ошибки — так выглядят ошибки во всех формах |
| `04-startseite-mobil.html` | Главная на телефоне: шапка, первый экран, нижняя панель |
| `05-3d-szene-mobil.html` | 3D-секция на телефоне |
| `screenshots/` | Те же экраны картинками. Главная разбита по секциям (`01a`…`01k`), чтобы сравнивать по частям; `01-startseite-komplett.png` — вся главная целиком |
| `assets/` | Шрифты макета и их лицензии (SIL OFL 1.1) |

Порядок блоков главной: шапка → первый экран → «Was wir bauen» → 3D-сцена → «Ausgewählte Projekte» → «So läuft Ihr Auftrag» → «Wir suchen Verstärkung» → «Familienbetrieb seit 1989» → «Was Kunden sagen» → «Sprechen Sie mit uns» → подвал. Плашка «Betriebsurlaub» над шапкой в макете не показана — она появляется, только когда отпуск включён в админке.

## Правила для агента

1. **Макет — образец внешнего вида, а не код.** Разметку и инлайн-стили не копировать. Собирать на компонентах проекта, классах Tailwind и токенах из `globals.css`.
2. **Цвета — только токены** (таблица ниже). Других цветов на сайте нет. Цвета из раздела «Только макет» на сайт не переносить.
3. **Шрифты и размеры — по шкале брифа** (раздел 3). Если макет расходится со шкалой на 1–2 px, бери шкалу.
4. **Отступы.** Единица Tailwind стандартная, 4 px: px из макета делим на 4. 8 px → `2`, 16 → `4`, 24 → `6`, 32 → `8`, 48 → `12`, 64 → `16`, 96 → `24`, 128 → `32`. Мелкие зазоры 4 и 12 px внутри компонентов допустимы (`1`, `3`).
5. **Проверка результата.** Сделай Playwright-скриншот своей страницы той же ширины — 1440 px для компьютера, 390 px для телефона — и сравни со скриншотом той же секции из `screenshots/`. Расхождения в цветах, размерах шрифтов, отступах и порядке блоков исправить.
6. **Тексты в макете — образец содержания.** На сайте текст интерфейса берётся из `messages/*.json`, контент — из Payload.
7. **Чего в макете нет:** страницы услуг, работ, о нас, вакансий, контактов, юридические страницы, 404, открытое мобильное меню. Собирать их из тех же компонентов и в том же стиле: такие же заголовки, кнопки, карточки, расстояние между секциями — 128 px на компьютере и 64 px на телефоне.
8. **Узкие экраны.** Шапка с меню в строку, как в `01`, — от 1280 px (`xl`): уже она не помещается в одну строку. До 1280 px шапка как в `04` — логотип и кнопка «Menü», меню открывается на весь экран. Нижняя панель «Anrufen / Anfrage» — только на телефонах, до 768 px (`md`), и не на страницах с формами. На телефоне остальные блоки — те же, что на компьютере, в одну колонку.

| Hex | Токен | Где в макете |
|---|---|---|
| `#F8F9F7` | Papier | фон страниц |
| `#FFFFFF` | Weiß | поля форм, карточка формы, текст кнопок, заголовки в подвале |
| `#24282A` | Graphit | основной текст, заголовки, фон подвала |
| `#5B6266` | Schiefer | второстепенный текст, разделитель в подвале |
| `#D6DBD8` | Linie | декоративные линии и разделители, неактивные шаги, мелкий текст в подвале |
| `#7C8482` | Feldrand | рамки полей, вариантов выбора и кнопки «Menü» |
| `#1F4537` | Tannengrün | кнопки, ссылки, логотип, активный шаг |
| `#15332A` | Tannengrün dunkel | ссылки и кнопки при наведении |
| `#E4EBE6` | Moos | подложка секций и блока «Lieber telefonieren?», выбранный вариант в форме, текст в подвале |
| `#B42318` | Fehler | ошибки в формах |

**Feldrand** — новый токен, решение от 18.11.2026: у Linie контраст с фоном 1,3, а для рамок элементов управления нужно 3:1. У Feldrand на белом 3,8, на Papier 3,6, на Moos 3,2. Если его ещё нет в `globals.css` — добавить. Рамки полей цветом Linie не делать.

**Только макет, на сайт не переносить:**
- полосатые прямоугольники цвета дерева с белой подписью («Foto: …») — заглушки фото. На сайте вместо них настоящие фото из Payload через `next/image`, без подписей-заглушек;
- плоский рисунок шкафа и его тени в 3D-секции (коричневые, бежевые и серые оттенки).

## Что показано условно

- **3D-секция.** На главной показан один момент: активен шаг 3, шкаф нарисован плоско. На сайте — настоящая 3D-сцена по разделу 4 брифа: секция закрепляется на экране, шкаф собирается при прокрутке, шаги подсвечиваются по очереди. Как выглядят все шесть шагов — в `02`.
- **Ошибка в форме** в `03` показана специально, чтобы был виден её вид.
- **`[PLZ]`** — место для индекса, который ещё надо подобрать (чек-лист перед запуском, раздел 7 брифа).
- **Ноль с косой чертой** (0) — особенность шрифта Atkinson Hyperlegible Next, чтобы ноль не путали с буквой O. Так и должно быть.
- Ссылки в макете ведут либо на `#`, либо на другие файлы макета.
